# 床が変わったら

同じ初期状態・重力・ボールで床の反発係数のみ0.75から0.30へ変える簡略モデル。実材質の測定・再現ではなく、変形、接触時間、摩擦、回転、空気抵抗は省略。接触前は同一、初回接触は0.55秒。途中で床が魔法のように変わるのではなく、別の床で同じ投球を比較する。

元のモデルはexperience01からそのまま保持。新モデルはtrain.pyで実際に訓練。入力・構造・seed・標本数は同じ、教師データの反発係数のみ変更。各24,000候補の15%内部検証、独立seedの6,000組テスト。ブラウザでの再学習なし。床を入力にしない2つの専用モデルであり材質認識ではない。

初期条件は前作の「下へ投げる」を継承。新しいモデルの１ステップテスト高さMAEは0.0128m、1.1秒後の位置誤差は0.4944m。旧モデルは変更後の床で2.4516m。軌跡平均誤差は旧0.7834m、新0.1202m。少数のデモ条件での結果であり汎用性能を示さない。モデル改善のためにテストデータで調整していない。小さい１ステップ誤差でも反復でずれが累積する。

再現: requirements.txtの環境で `OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python experiments/floor-transfer/train.py`、`node tests/floor-transfer.test.cjs`。

検証: Python/JSの独立推論fixtures一致、接触前状態一致・反射方向、有限性、同じ初期条件・同じ予測時間、変更後の床に対する誤差比較。学習・推論・処理は検証済み。実ブラウザの表示・操作は未確認。

目的との対応: 自然な接触条件の変更から、学習分布・汎化・状態表現を知る。視覚差だけで実物理の理解や現実性能を主張しない。元のモデルが新しい床でずれても、学習一般の欠陥とは扱わない。
